# 智能厨房助手 Smart Kitchen Assistant

一款基于 AI 的智能厨房助手 App，帮助用户从识别食材到完成烹饪的全流程管理。拍照识别食材 → 智能菜谱推荐 → 购物清单管理 → 分步烹饪引导。

## 功能概览

| 模块 | 功能 | 说明 |
|------|------|------|
| 拍照识菜 | 食材识别 | 拍摄冰箱照片，通义千问视觉模型自动识别食材 |
| 菜谱推荐 | 智推荐 + 反查 | 根据已有食材推荐菜谱，或输入菜名查询所需食材 |
| 购物清单 | 一键生成 | 对比已有食材，自动生成需购买的清单 |
| 烹饪引导 | 分步计时 | 分步骤烹饪指引，每步支持独立倒计时和声音提醒 |
| AI 助手 | 对话问答 | LangChain Agent 驱动的厨房问答助手 |
| 收藏夹 | 菜谱收藏 | 收藏喜欢的菜谱，快速查找 |
| 待办事项 | Todo 管理 | 管理购物清单待采购事项 |
| 个人中心 | 账号管理 | 手机号 + 密码登录，个人资料管理 |

## 技术栈

**后端**

- Python 3.9+ / FastAPI
- SQLAlchemy (async + aiosqlite)
- LangChain (ReAct Agent)
- 阿里云通义千问 (qwen-vl-max 视觉 + qwen-turbo 文本)
- JWT (HS256) + bcrypt 认证

**前端**

- Flutter 3.0+
- Riverpod 状态管理
- GoRouter 路由
- Dio HTTP 客户端
- Hive 本地存储
